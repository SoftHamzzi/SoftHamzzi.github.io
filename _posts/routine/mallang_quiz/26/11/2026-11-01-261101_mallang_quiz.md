## Q6. 🔴 어려움 · 📌 오답노트 (3번째 복습)

C++의 `const`에 대해 답하시오.

(1) 아래 세 포인터 선언에서 각각 포인터 자체를 수정할 수 있는지, 가리키는 데이터를 수정할 수 있는지 쓰시오.

```cpp
char greeting[] = "Hello";
const char *       p1 = greeting;
char * const       p2 = greeting;
const char * const p3 = greeting;
```

(2) 아래 코드에서 `const vector<int>::iterator it`와 `vector<int>::const_iterator cit`는 각각 `*it = 10;`, `++it;`, `*cit = 10;`, `++cit;` 중 무엇이 가능하고 무엇이 불가능한가?

```cpp
vector<int> vec;
const vector<int>::iterator it = vec.begin();
vector<int>::const_iterator cit = vec.begin();
```

(3) 아래 코드는 `operator[]`가 `const` 멤버 함수이므로 컴파일은 되지만, 상수 객체 `cctb`의 내용이 바뀐다. 이런 일이 벌어지는 이유를 "비트수준(물리적) 상수성"의 정의와 연결해 설명하고, 이를 보완하기 위해 나온 개념(논리적 상수성)의 정의를 쓰시오.

```cpp
class CTextBlock {
public:
	char& operator[](size_t position) const { return pText[position]; }
private:
	char* pText;
};

const CTextBlock cctb("Hello");
char* pc = &cctb[0];
*pc = 'J';
```

(4) 아래 `length()`는 값을 캐시해 두려고 `const` 멤버 함수 안에서 멤버를 수정하다가 에러가 난다. 에러가 나는 이유와 해결 방법(키워드와 그것을 붙일 대상)을 쓰시오.

```cpp
class CTextBlock {
public:
	size_t length() const;
private:
	char* pText;
	size_t textLength;
	bool lengthIsValid;
};

size_t CTextBlock::length() const {
	if(!lengthIsValid) {
		textLength = strlen(pText);
		lengthIsValid = true;
	}
	return textLength;
}
```

> **출처:** `game_dev/cpp/chapter1/2025-04-06-cpp_1_3.md`
> **오답노트:** `wn-628f38c5` · 2026-09-10 최초 오답 · 이번이 3번째 복습

**📝 내 풀이:** (1) const char * 는 포인터 O, 데이터 X  
char * const 는 포인터 X, 데이터 O  
const char * const는 포인터 X, 데이터 X

(2) *it=10 O, ++it X, *cit=10 X, ++cit O

(3) 비트수준 상수성은 어떤 비정적 데이터 멤버라도 수정이 되지 않아야 const라는 규칙이다.  
하지만 내부에서 지켜진다 하더라도, 내부 참조값을 반환해버리는 경우 이러한 규칙이 깨진다.  
이를 위해 나온것이 논리적 상수성으로, 외부에서 알아차리지 못하게 내부 상태를 수정하면 괜찮다는 규칙이다.

(4) textLength와 lengthIsValid의 값을 변경하고 있기 때문이며, 이들 자료형 앞에 mutable을 붙여주면 된다.
